# A sample `DESeqResults` object

A sample `DESeqResults` object, generated with `DESeq2`

## Format

A `DESeqResults` object

## Value

A sample `DESeqResults` object, generated with `DESeq2`

## Details

This `DESeqResults` object contains the results of a Differential
Expression Analysis performed on data from the `macrophage` package,
more precisely contrasting the counts from macrophage associated with
Salmonella to those associated with IFNg and Salmonella.

The code to create said object can be found in the folder
`/inst/scripts` in the DeeDeeExperiment package, the file is called
`generate_data.R`.
