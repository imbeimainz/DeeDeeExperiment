# `clusterPro_res`

A list of FE results generated with
[`clusterProfiler::enrichGO()`](https://rdrr.io/pkg/clusterProfiler/man/enrichGO.html)

## Format

A list of `enrichResult` objects

## Value

A list

## Details

A list of FE result for the macrophage data (salmonella vs naive and
IFNg vs naive)
