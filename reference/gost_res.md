# `gost_res`

A list of FE results generated with
[`gprofiler2::gost()`](https://rdrr.io/pkg/gprofiler2/man/gost.html)

## Format

A list, as returned by `gprofiler2`

## Value

A list

## Details

A list of FE result for the macrophage data (salmonella vs naive)
